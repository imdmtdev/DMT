# 🚀 DMT Website - Digital Marketing & Technology

Website công ty thiết kế website chuyên nghiệp DMT, được xây dựng với Next.js, TailwindCSS và Framer Motion.

## ✨ Tính năng nổi bật

- 🎨 **Giao diện hiện đại**: Gradient đẹp mắt, animation mượt mà
- 📱 **Responsive 100%**: Tối ưu cho mọi thiết bị
- ⚡ **Performance cao**: Core Web Vitals tối ưu
- 🔍 **SEO-friendly**: Meta tags đầy đủ, sitemap, robots.txt
- 🎭 **Animations**: Framer Motion cho trải nghiệm mượt mà
- 🎯 **CTA tối ưu**: Nút liên hệ cố định, scroll to top
- 🌈 **Theme hiện đại**: Glass effect, gradient, hover effects

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: TailwindCSS
- **Animation**: Framer Motion
- **Icons**: React Icons
- **Language**: TypeScript
- **Deploy**: GitHub Pages

## 📦 Cài đặt

```bash
# Clone repository
git clone <your-repo-url>

# Cài đặt dependencies
npm install

# Chạy development server
npm run dev

# Build production
npm run build

# Deploy lên GitHub Pages
npm run deploy
```

## 🚀 Deploy lên GitHub Pages

1. Push code lên GitHub repository
2. Vào **Settings → Pages**
3. Source: chọn **GitHub Actions**
4. Website sẽ tự động deploy khi push code lên branch `main`

### Cấu hình Custom Domain

1. Thêm DNS records tại nhà cung cấp domain:
```
Type: A, Name: @, Value: 185.199.108.153
Type: A, Name: @, Value: 185.199.109.153
Type: A, Name: @, Value: 185.199.110.153
Type: A, Name: @, Value: 185.199.111.153
```

2. Vào repo → Settings → Pages → Custom domain: nhập `dmt.vn`
3. Chờ DNS verify (24-48h)
4. Bật **Enforce HTTPS**
