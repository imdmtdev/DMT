📌 TỔNG QUAN: 3 bước đơn giản
   1. Tạo repository trên GitHub (1 phút)
   2. Push code lên GitHub (1 phút)
   3. Bật GitHub Pages (30 giây)

════════════════════════════════════════════════════════════

🔹 BƯỚC 1: TẠO REPOSITORY TRÊN GITHUB
────────────────────────────────────────────────────────────

1.1. Đăng nhập GitHub:
     → https://github.com/login
     → Username: dangminhtri123

1.2. Tạo repository mới:
     → https://github.com/new
     
     Điền thông tin:
     ┌─────────────────────────────────────────┐
     │ Repository name: DMT                    │
     │ Description: Website công ty DMT        │
     │                                         │
     │ ✅ Public                               │
     │ ❌ KHÔNG tick "Add a README file"      │
     │ ❌ KHÔNG tick "Add .gitignore"         │
     │ ❌ KHÔNG tick "Choose a license"       │
     └─────────────────────────────────────────┘

1.3. Click nút "Create repository"

════════════════════════════════════════════════════════════

🔹 BƯỚC 2: PUSH CODE LÊN GITHUB
────────────────────────────────────────────────────────────

2.1. Double-click file: PUSH_TO_GITHUB.bat

2.2. Đăng nhập khi được yêu cầu:
     Username: dangminhtri123
     Password: [Personal Access Token]

     ⚠️ QUAN TRỌNG: Password là TOKEN, không phải password thường!

════════════════════════════════════════════════════════════

🔐 TẠO PERSONAL ACCESS TOKEN (Nếu chưa có)
────────────────────────────────────────────────────────────

Bước 1: Truy cập
        → https://github.com/settings/tokens

Bước 2: Click "Generate new token" 
        → Chọn "Generate new token (classic)"

Bước 3: Điền thông tin
        ┌─────────────────────────────────────┐
        │ Note: DMT Website Deploy            │
        │ Expiration: No expiration           │
        │ ✅ repo (tick tất cả các mục con)  │
        └─────────────────────────────────────┘

Bước 4: Click "Generate token"

Bước 5: COPY TOKEN NGAY (chỉ hiện 1 lần!)
        Lưu vào notepad để dùng lại

════════════════════════════════════════════════════════════

🔹 BƯỚC 3: BẬT GITHUB PAGES
────────────────────────────────────────────────────────────

3.1. Vào repository:
     → https://github.com/dangminhtri123/DMT

3.2. Click tab "Settings" (ở trên cùng)

3.3. Click "Pages" (menu bên trái)

3.4. Tại "Source", chọn: "GitHub Actions"

3.5. Xong! Không cần làm gì thêm

════════════════════════════════════════════════════════════

🔹 BƯỚC 4: KIỂM TRA WEBSITE
────────────────────────────────────────────────────────────

4.1. Click tab "Actions" trên repository

4.2. Xem workflow "Deploy to GitHub Pages"
     - Màu vàng 🟡 = Đang chạy
     - Màu xanh ✅ = Thành công
     - Màu đỏ ❌ = Có lỗi

4.3. Chờ 2-3 phút

4.4. Truy cập website:
     → https://dangminhtri123.github.io/DMT/

════════════════════════════════════════════════════════════

🔄 CẬP NHẬT WEBSITE SAU NÀY
────────────────────────────────────────────────────────────

Mỗi khi thay đổi code:

Cách 1: Double-click file UPDATE_WEBSITE.bat

Cách 2: Chạy lệnh:

        git commit -m "Mô tả thay đổi"
        git push

→ GitHub tự động build và deploy lại!

🌐 NỐI CUSTOM DOMAIN (Tùy chọn)
────────────────────────────────────────────────────────────

Nếu bạn có domain riêng (vd: dmt.vn):

Bước 1: Sửa file public/CNAME thành: dmt.vn

Bước 2: Cấu hình DNS tại nhà cung cấp domain:
        Type: A, Name: @, Value: 185.199.108.153
        Type: A, Name: @, Value: 185.199.109.153
        Type: A, Name: @, Value: 185.199.110.153
        Type: A, Name: @, Value: 185.199.111.153

Bước 3: Settings → Pages → Custom domain → Nhập: dmt.vn

Bước 4: Chờ 24-48 giờ để DNS cập nhật

🆘 XỬ LÝ LỖI THƯỜNG GẶP
────────────────────────────────────────────────────────────

❌ Lỗi: "Authentication failed"
   → Dùng Personal Access Token thay vì password

❌ Lỗi: "Repository not found"
   → Kiểm tra đã tạo repository trên GitHub chưa

❌ Lỗi: "Permission denied"
   → Token phải có quyền "repo"

❌ Website 404
   → Kiểm tra đã bật GitHub Pages chưa
   → Chờ 2-3 phút sau khi deploy

❌ CSS/JS không load
   → Đã có trong next.config.js, không cần sửa
